3. Team-Managed Projects vs Company-Managed Projects
====================================================

Team-Managed Projects
---------------------
You don't need any special permissions to create a team-managed project. Also Jira administrator can control who can create team-managed projects.


	Team-Managed Project A						Team-Managed Project B
		   |								   |
	   -----------------						   ------------------
	   |		   |						   |		    |
	Status		Issue Type					Status		Issue Type
	   |		   |						   |		    |
   To Do---|		   |----Epic			In Testing---------|  		    |---Task		
In Progress|		   |----Story			Re-Test Required---|		    |---New Feature
    Done---|  		   |----Bug			Passed QA----------|  		    |---Change Request
	   

Entities in Projects A and B can be changed for the Project specific needs - Issue Types and Status. The entities live only in the team-managed projects - project scope netities.



Company-Managed Projects
------------------------
Company managed project are using global entities. 


			Global Entities
				|
		  Status-----------------Issue Type				Project A 	 Project B
		     |			      |						|		|
	     To Do---|			      |---Epic					|		|
       In Progress---|			      |---Story					|		|
	      Done---|			      |---Bug					|		|
	In Testing---|			      |---Task					|		|
Re-Testing Required--|			      |---New Feature   -----------------------------------------
	Passed QA ---|			      |---Change Request
		  ---|			      |---


Project A and Project B cam use the same type from global Entities. When an entity is changed, it is changed in all projects that are using this entity. This suggest that we are using company managed project if the project is very similar to already created projects that using the same entities.




4. Create a Team-Managed Project
================================
When we are not logged in as administrator, we can still create a Team-Managed Projects.

We can create project from Jira Menu tab: 'Projects/Create Project'. We can choose different templates to start our project.
- Different templates can be free to use or on trail period. 

Free Trials templates
---------------------
The difference is When we choose the template we can see the button 'Try this template' or 'Use this template'. 
Message 'Try this template' means that the template is not free and can have some restrictions (Example template Service Management/IT service management). We can see under the header of the template that there is a product - 'Jira Service Management - TRY/PREMIUM' with special character.


Step 1: Choose template
We can use free project template - Software development/Kanban 
- Click 'Use template' to proceed.

Step 2: Choose between Team-managed Project or Company-managed project
- If we are not logged as administrator, we cannot create Company-Managed Project
- We cannot change the type of the project later. If we want to set a Company-Managed Project, we need to create new project.
- Choose Team-Managed Project

Step 3: Set Project details
- Set Project Name: Podcast Mobile App Development
- Set Project Key: APP
Key explanation:
	- if our project key is 'DEV', the issues are going to be created with names DEV-1, DEV-2,DEV3, etc. Also the URLs of the issues are going to be as DEV-2126, DEV-4214 etc.
	- Key must be unique
- Set Project permissions - Open - Free

- Press 'Craete' button

Step 3: Invite Team members
	- Skip this step

Step 4: Connect Your Work
	- BitBucket
	- Confluence
- click 'Continue' to skip this step also

We have now new Project created.

5. Creating issues in Team-Managed Project
==========================================
There a few ways to create an issue:
- Create button/Epic or Task. 
- Shortcut - 'C'

Main fields:
------------
Project - when we change the project, issue types (entities) are also changed.
Issue Type - Epic/Task
	- We can create custom issue types for this project
Summary - we need to fill the summary/short description of the issue
	- set 'Create podcast playlist feature to allow users to queue episodes'
Reporter - automatically assigns the creator of the issue

- click 'Create' button

Additional fields in create issue form
	- whatcher - we can add team members to receive notifications
	- Configure fields - we can customize fields to this entity

8. Configuring the Agile Board
==============================
We have created several more work items and New Features

On the right side we can filter the work items by team meber and type.
On the left side 
	- we can filter by group. This option creates a group list for each Assignee or Subtask
	- we can also configure new custom filters and manage existing fiters
		- manage Custom Filters
			Name: New Feature
			Filter query: issuetype = "New Feature"
			Create
		- now on the board we have custom filter - New Feature

	- We can set different dependencies 
	- We can set different statuses in one column

14. Explaining Jirda Issue navigator
====================================

In 'All Work' tab we can select any item and on the right side will appear item navigator. We can perform any changes connected with the selected issue/item.

We have Hystory, comments and Work log to see what and who changed parameters for each issue/item.
On work log we can set commited time spent for the issue/item.

If we are administrator we can add or crete fields for each issue/item from the navigator section. We can pin fields to appear in any other isses/items in the project.

16. Daily Workflow of managing project
======================================

Stand UP in the morning
-----------------------
This functionality is implemented for easy meeting management. It has included timer. We set few minutes for every member to answer these 3 questions:
	- What did you d oyesterday?
	- What will you do today?
	- Are there any blockers preventing progress?

Drag and drop work items to different board columns.

Set blocked status on work item
-------------------------------
We can edit work items in the 'In Progress' column and link other issues that are blocking the work over this one.
	- Work item/Link work item
		- Select link type: os blocked by
		- Select work item: blocking item
		- Link

Set Flag to pull attention to specific work item/issue
------------------------------------------------------
	- Work item/Flag/Set message - 'Blocked, lets discuss on the next stand up'
Now the work item will be in different color and will draw attention
	
On the right side menu we can open Board Insights and see information about different work items/issues
